# 家計簿 エクセル｜夫婦の精算と特別費を計算してExcelに出す家計簿 テンプレート（カードCSV読込・銀行連携なし）

[https://jmshinhwa.github.io/rulestamp-tools/household-budget-planning/](https://jmshinhwa.github.io/rulestamp-tools/household-budget-planning/)

## できること

家計簿 エクセル：夫／妻／共通の支出から、予算との差・負担割合どおりの夫婦精算・年払いの特別費の毎月の積立をその場で計算。銀行ログインなしでカード明細CSVを読み込み、数式入りの .xlsx（今月・精算・特別費・年間・明細）に保存する家計簿 テンプレート。 家計簿 エクセル – 家計簿 テンプレートの手打ちも、家計管理 アプリの口座連携もいらない夫婦の家計簿。 記入例（架空の世帯）：外食は予算 ¥15,000 に対して ¥22,410 で ¥7,410 のオーバー。共通の支出 ¥201,620 を 6:4 で分けると、今月の精算は「妻→夫 ¥27,548」。来月の自動車保険 ¥60,000 は毎月 ¥5,000 の積立で用意できる計算です。 • 銀行・カードにログインしないので「連携が切れて更新されない」が起きません。カード会社・銀行のサイトから落とした明細CSV（UTF-8 / Shift_JIS）をブラウザの中で読み、日付・利用先・金額の列を見出しから探して、お店の名前で分類します。 • 1行ごとに 夫／妻／共通 を選ぶと、負担割合（例 6:4、または収入比）どおりの精算「今月 妻→夫 ¥◯」と計算式が画面に出ます。 • 年払いの特別費（自動車税・固定資産税・保険など）を 12 で割った毎月の積立と、払う月の表示。 • 数式入りの .xlsx（今月・精算・特別費・年間・明細の5シート）。Excel・Googleスプレッドシート・Numbersで開けます。印刷・PDFも。 • アカウント不要・広告なし。データはこのブラウザの中だけ。表示言語：日本語・English・Deutsch・Español・Português。 無料：1世帯・1か月分、行数の制限なし。予算と実績、夫婦精算、特別費の積立まで全部画面に出ます。 できないこと：銀行・カードの自動連携、2台のスマホでのリアルタイム共有、メール・プッシュ通知はありません（別の端末へはバックアップファイルで移せます）。
