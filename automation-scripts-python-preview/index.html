How the scripts decide


Overdue invoices: an invoice is open while the paid-on cell is empty (or, if your file has an amount-paid column, while amount minus paid is above zero). Days late = the check date minus the due date. Buckets 1-30, 31-60, 61-90 and 91+ days; "enters next bucket" is the date it moves up. One reminder per client lists all of that client's late invoices; past 30 days the wording is firmer, past 60 it is a final reminder. The script writes the drafts; it does not send email.


Duplicate contacts: emails are compared without spaces and capitals. The first row is kept and empty cells in it are filled from its duplicates. Rows without an email can be matched on the last 10 digits of the phone number.


Bank categories: the first rule whose words appear in the description wins. Money in without a rule is "Income (no rule)", money out without a rule is "Uncategorized", so you see exactly which rules to add.


Rename and sort files: names that would collide get -2, -3. The script shows the plan and changes nothing until you add --go; then it writes an undo log.


Split CSV: one file per value of the column you pick, with the same columns as the original, largest group first.


Amounts like $1,250.00, 1.250,00 € and (59.99) are read; dates as 2026-11-18, 11/18/2026 or 18.11.2026. The page and the Python file use the same rules; both were run on the same test files and gave the same answers.
